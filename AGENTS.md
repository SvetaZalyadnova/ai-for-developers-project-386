# AGENTS.md

## О проекте
Сервис бронирования календаря: гости выбирают свободные слоты и записываются без авторизации.

## Стек и архитектура
- **Бэкенд:** Java 17+, Spring Boot.
- **Фронтенд:** React, TypeScript, Vite.
- **API:** TypeSpec — исходный контракт; OpenAPI и клиентский SDK генерируются из него.
- **Хранение:** бронирования находятся в памяти процесса и сбрасываются при перезапуске.

При изменении API сначала обновляйте TypeSpec, затем регенерируйте спецификацию и SDK предусмотренными проектом командами. Не редактируйте сгенерированные файлы вручную.

## Бизнес-правила
- Доступны слоты на следующие 14 календарных дней.
- Учитывайте рабочие часы, часовой пояс календаря, длительность встречи и уже занятое время.
- Запрещайте пересечение встреч; разрешайте следующей встрече начинаться ровно в момент окончания предыдущей.
- Обеспечивайте защиту от одновременного бронирования одного времени.

## Команды разработки и проверок
- **Сборка бэкенда:** `cd backend && mvn clean package`
- **Запуск бэкенда:** `cd backend && mvn spring-boot:run`
- **Тесты бэкенда:** `cd backend && mvn test`
- Перед запуском проверяйте манифесты и доступные скрипты в соответствующем каталоге; не предполагайте команды фронтенда или TypeSpec, если они не описаны в проекте.
- Перед завершением изменений запускайте наиболее подходящие тесты и проверки затронутой части проекта.
