# AGENTS.md

## Проект
- Фронтенд: React, TypeScript, Vite. Бэкенд: Java 17+, Spring Boot.
- Сейчас бронирования работают только в демо-фронтенде и хранятся в состоянии страницы; backend предоставляет только `GET /api/health`.
- Для будущих бронирований учитывать окно 14 календарных дней, рабочие часы, часовой пояс и длительность; запрещать пересечения, разрешать старт в момент окончания предыдущей встречи и защищать от конкурентной записи.

## Работа с кодом
- Перед изменением API проверьте наличие исходного контракта и команд генерации. Если они есть, обновляйте контракт и регенерируйте SDK/OpenAPI; не редактируйте сгенерированные файлы вручную.
- Не предполагайте команды разработки: сверяйтесь с `mise.toml`, манифестами и скриптами проекта.
- Перед завершением запускайте релевантные проверки; полный набор: `mise run check`.
- Запуск бэкенда: `cd backend && mvn spring-boot:run`.
