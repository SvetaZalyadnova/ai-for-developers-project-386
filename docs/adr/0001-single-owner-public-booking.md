# Один владелец и публичная запись

Сервис рассчитан на одного заранее заданного владельца календаря. Гости выбирают тип встречи и бронируют свободное время без регистрации; активные типы доступны публично через `GET /api/v1/meeting-types`. Авторизация, личные кабинеты и интеграции с внешними календарями не входят в область проекта. Это сохраняет приложение небольшим и сосредоточенным на основном сценарии записи.
