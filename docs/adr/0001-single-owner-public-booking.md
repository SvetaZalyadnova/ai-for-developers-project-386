# Один владелец и публичная запись

Сервис рассчитан на одного заранее заданного владельца календаря. Гости выбирают тип встречи и бронируют свободное время без регистрации; публичные маршруты не требуют авторизации. Закрытые маршруты управления владельца под `/api/v1/owner` защищены Bearer-токеном, заданным только на сервере. Личные кабинеты и интеграции с внешними календарями не входят в область проекта.
