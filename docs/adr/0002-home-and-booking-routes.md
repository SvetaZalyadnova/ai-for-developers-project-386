# Отдельные маршруты главной и записи

Главная страница доступна по `/`, а существующий интерфейс записи — по `/booking`; для маршрутизации используется React Router, а неизвестные адреса показывают страницу 404 со ссылкой на главную. Отдельные адреса позволяют главной объяснять сервис, не заменяя текущий сценарий записи, и поддерживают прямое открытие обеих страниц.
