# Календарь звонков


[![hexlet-check](https://github.com/SvetaZalyadnova/ai-for-developers-project-386/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/SvetaZalyadnova/ai-for-developers-project-386/actions)

Разработайте совместно с ИИ сервис для бронирования календаря

Учебный проект Хекслета: https://ru.hexlet.io/programs/ai-for-developers
Как это должно работать: https://files.hexlet.app/a/2ipc5m
Упрощенный аналог Cal.com для бронирования встреч. Позволяет владельцу календаря публиковать доступные типы встреч, а гостям — выбирать свободные слоты на 14 дней вперед и записываться на звонки без регистрации и личных кабинетов.

## 🚀 Основные возможности

* **Для владельца:**
  * Предзаданный единственный владелец календаря.
  * Управление типами встреч (название, описание, длительность).
  * Просмотр списка всех предстоящих встреч.
* **Для гостя:**
  * Просмотр доступных слотов на ближайшие 14 календарных дней (с учетом рабочих часов, часового пояса и уже занятого времени).
  * Быстрая запись на выбранный слот без авторизации.
  * Защита от пересечения интервалов и гонки запросов (race conditions).

## ⚙️ Правила и ограничения бизнес-логики

1. **Окно записи:** Ровно 14 календарных дней, сдвигается с течением времени.
2. **Рабочее время:** Настраивается в конфигурации бэкенда (например, с 09:00 до 18:00 в часовом поясе UTC).
3. **Конфликты и пересечения:** Пересечение интервалов строго запрещено, включая частичное наложение разных типов встреч. Следующая встреча может начинаться в момент окончания предыдущей. Механизм синхронизации защищает от одновременных запросов на один и тот же слот.
4. **Хранение:** Приложение работает в памяти процесса (`In-Memory`). **Внимание:** при перезапуске сервера все созданные бронирования удаляются.

## 📦 API и Контракты (TypeSpec & OpenAPI)

Проект спроектирован по принципу *Contract-First*:
1. Исходный контракт описан с помощью **TypeSpec**.
2. Из него сгенерирована **OpenAPI** спецификация.
3. Для фронтенда сгенерирован **клиентский SDK**.
